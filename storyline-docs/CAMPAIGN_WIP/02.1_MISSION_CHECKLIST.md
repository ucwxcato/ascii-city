## MISSION CREATION PER-MISSION CHECKLIST

Use this for EACH mission created:

### 1. Pre-Creation
- [ ] Review mission place in arc (`00.md`)
- [ ] Identify mission type (Tutorial, Faction, Story, Climax)
- [ ] Note story flags to set/require
- [ ] Confirm tier and difficulty
- [ ] Check prerequisite missions exist

### 2. JSON Structure
- [ ] All required fields in `mission_meta`
- [ ] `id` follows: `t{tier}_{sequence}_{slug}`
- [ ] `category` matches directory
- [ ] VFS children are objects, NOT arrays (CRITICAL)
- [ ] All node_ids unique
- [ ] All IP addresses unique
- [ ] File paths are absolute (start with `/`)

### 3. Win Conditions
- [ ] Objective types are valid enum values
- [ ] `target_node` references valid node_id
- [ ] `target_path` exists on that node
- [ ] Sequential missions have matching structure
- [ ] No contradictory objectives

### 4. Narrative Content
- [ ] Faction email voice consistent
- [ ] Architect persona matches arc phase
- [ ] Environmental files add worldbuilding
- [ ] No placeholder "TODO" content
- [ ] Appropriate clue subtlety for arc

### 5. Testing
- [ ] Run `npm run predev` to regenerate index
- [ ] Validate JSON structure
- [ ] Test mission loads from mail
- [ ] Test win conditions trigger
- [ ] Test rewards apply correctly
- [ ] Test story flags set/unset
- [ ] Test abort mission works

**Refer to:** `02.md` Part 4 (Quality Checklist), Part 5 (Testing Procedures), Part 7 (Step-by-Step Creation)

## CRITICAL VFS RULES (Read This!)

1. **NEVER use arrays for directory children:**
   ```json
   // WRONG - Will crash!
   "children": [ { "name": "file.txt" } ]

   // CORRECT
   "children": { "file.txt": { "type": "file" } }
   ```

2. **ALWAYS use absolute paths:**
   ```json
   // WRONG
   "target_path": "home/user/file.txt"

   // CORRECT
   "target_path": "/home/user/file.txt"
   ```

3. **Node transitions must reset currentDirectory:**
   - Use `MissionManager.handleNodeConnection` middleware
   - Prevents "Node Ghosting"

**Refer to:** `02.md` Part 9 (Common Pitfalls & Solutions), `AGENT.md` lines 171-191
