# ASCII City Unity Authoring Project

Open this folder (`tools/unity-authoring-project`) from Unity Hub. It uses the local `tools/unity-world-authoring` package and defaults the authoring window to the repository's `assets/maps` folder. The project is pinned to the installed Unity Editor version, 6000.0.75f1.

In Unity, open **Tools > ASCII City > World Authoring**, choose a map, then select **Create / sync scene**. The map opens as a 3D Scene view workspace where you can paint grid cells, place real prefab assets, and save/export placements.
